# TML Appointment Journey (demo)

Clickable demo of how the Appointment module is handled by TML positions (NSM, RSM, ZSM, RCSM) and dealer roles (Dealer GM, CRM, CRE, Dealer Service Admin).

- Open `index.html` (or the published page). No build step, no backend.
- Region, zone, area and dealer names are fake placeholders, not real TML geography. Data on the dealer screens is the sandbox data shown in the Figma prototype (not production).
- Screens marked **Proposed** are design proposals, not existing screens.
